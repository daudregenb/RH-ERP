# RH-ERP System

Sistem Enterprise Resource Planning (ERP) berbasis web menggunakan framework **Laravel** yang dirancang untuk mengoptimalkan manajemen inventaris, kontrol stok gudang, dan otomatisasi administrasi rantai pasok.

## 🚀 Fitur Utama
- **Autentikasi & Otorisasi:** Akses pengguna berbasis peran (Role-Based Access Control / RBAC).
- **Manajemen Inventaris:** Pemantauan masuk-keluar barang, pencatatan SKU, dan notifikasi stok minimum otomatis.
- **Audit & Opname Stok:** Pelacakan riwayat transaksi barang dan rekapitulasi data opname.
- **Integrasi & Pelaporan:** Pengolahan data inventaris dengan ekspor/impor ke format spreadsheet.

## 🛠️ Modul & Teknologi
- **Framework Backend:** Laravel (PHP)
- **Database:** MySQL / PostgreSQL
- **Frontend UI:** HTML5, CSS3, JavaScript / Tailwind CSS / Bootstrap
- **Version Control:** Git & GitHub
